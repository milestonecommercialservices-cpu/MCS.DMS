# MCS.DMS
Local AI: A deterministic execution layer for local models, AI instruction encoding.

Based on dewey decimal, Milestone Commercial Services database management system (MCS.DMS) provides a manifest to a locally running AI model to call a specific tool (Python3) and trigger a pre-made program. Essentially restricting a local model to the task of routing rather than code generation or slow inefficient search of a entire system's folder and directories. 

It's purpose is to make local AI more viable for difficult tasks and reduce dependency and load on external infrastructure, while eliminating errors from hallucination, compression, and file navigation errors.

It is designed to integrate with NAS systems allowing entire subjects related to a specific Dewey decimal system addressed category to be stored to a specific drive, and if needed, physically removed entirely. This includes tools or information that a model may attempt to gain access to without permission.
